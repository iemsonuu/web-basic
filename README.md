# Web & Security Foundations

An interactive, beginner-friendly course that takes students from "what is the web?" to the **OWASP Top 10:2025**. It is a single HTML file with no install, no build step and no dependencies.

## What you will learn

| Part | Modules |
|---|---|
| **Web basics** | What the web is, client–server communication, URL / domain / DNS, front end / back end / database |
| **HTTP** | HTTP & HTTPS (TLS handshake), requests and methods, responses and status codes |
| **Auth & security** | Cookies, sessions and authentication, web application security models |
| **OWASP Top 10:2025** | What OWASP is and why it matters, then one lesson for each risk A01–A10, plus a recap |

## Features

- **Animated network-map diagrams:** packets travel between laptops, routers, ISPs, servers and databases.
- **Step controls:** Play, Pause, Prev, Next, Restart and 0.5× / 1× / 2× speed.
- **Optional panels:** capture-style packet list, sequence diagram and packet inspector (plain-language).
- **Before and after** views for every OWASP risk: "without the fix" vs "with the fix".
- **Easy examples** and everyday analogies in every lesson, plus a check-your-understanding question.
- **Full HTTP reference:** all common methods and status codes with examples.
- **Quick reference sheet**, progress tracking and keyboard navigation (← →).
- **Colour themes:** ocean, emerald, violet, rose, amber, orange, indigo and teal.
- **Responsive**, works on phones and laptops.
